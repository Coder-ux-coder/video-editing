# Reference videos

Drop reference videos here (only ones you have the right to use). `cutroom analyze-reference
references/<file> --name <style>` analyses one in place (never copied or uploaded) and writes
`styles/<style>.style.yaml`: pause lengths its editor kept (between words and sentences),
pacing from its shot lengths, with the measurements in the file header. Graphics look, caption
style, music and colour are not measured automatically: the agent looks at the reference and
sets those by hand. Contents of this folder are not committed.
