# Assets

Fonts, SFX, LUTs and music, each with a sidecar `<file>.license.json` (source URL, licence, date retrieved) and a row in `docs/LICENSES.md`. Only CC0, public domain, OFL or royalty-free-for-client-work licences. If an asset cannot be obtained free and legally it is generated (procedural graphics, synthesised SFX) or skipped.

`samples/` holds the test clips `cutroom doctor` uses (see their `.json` files for provenance).
