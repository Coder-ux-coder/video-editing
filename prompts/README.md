# Agent playbook

Reusable instructions a Claude session loads and follows when editing (`00_orchestrator.md` … `10_delivery.md`). Each one covers purpose, inputs, procedure, decision rules, outputs, failure handling and a checklist.

Written stage by stage as the tools they call are built: 00–04 in Phase 1, 05–06 in Phase 2–3, 09 in Phase 4, 08 in Phase 5, 07 in Phase 6, 10 in Phase 7. A playbook is only written once its commands exist and are tested, so it never refers to tools that do not exist yet.
